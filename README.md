# Network-Intrusion-Detection-System-Using-Suricata
Intrusion Detection System (IDS) with SuricataOverviewThis project demonstrates the setup of a Suricata-based IDS on Kali Linux, configured with custom detection rules to identify suspicious traffic patterns. It includes both detection and automated response mechanisms, verified against live traffic.ObjectivesDeploy Suricata IDS on Kali Linux (VirtualBox environment).Write and test three custom rules:ICMP Ping DetectionTCP Port Scan DetectionHTTP GET Request DetectionVerify alerts in Suricata’s fast.log.Extend IDS with a bash response script that blocks malicious IPs after repeated alerts.Tools & EnvironmentOS: Kali Linux (VirtualBox)IDS Engine: Suricata 8.0.7Traffic Generators: ping, nmap, curl, Python http.serverInterface: eth0, target host 10.0.4.1Key StepsInstallation: sudo apt install suricata -yCustom Rules: Defined in /etc/suricata/rules/local.rulesConfiguration Fix: Corrected suricata.yaml to load local rules.Verification: Suricata logs confirmed “3 signatures processed.”Traffic Tests: ICMP, TCP port scan, and HTTP GET triggered alerts.Response Script:Monitors fast.log in real time.Blocks source IP after 5 port-scan alerts using iptables.Logs actions to /var/log/suricata_response.log.ResultsDetection: All three custom rules fired correctly.Response: Automated block applied to offending IP (10.0.4.26).Verification: DROP rule confirmed in firewall table.Auditability: Permanent log maintained with timestamps.ConclusionThis project successfully delivered a detect-and-respond IDS workflow, combining Suricata’s detection capabilities with a custom automated response mechanism.
